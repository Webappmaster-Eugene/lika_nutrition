## 🚀 Инструкция по деплою

1. **Подключите репозиторий в Dokploy**
   - Создайте новый проект
   - Выберите тип: **Docker Compose**
   - Подключите Git репозиторий

2. **Настройте переменные окружения**
   - Добавьте `NEXT_PUBLIC_SITE_URL` (обязательно)
   - Добавьте остальные переменные при необходимости

3. **Запустите деплой**
   - Dokploy автоматически найдет `docker-compose.yml`
   - Сборка займет ~2-5 минут
   - После сборки сайт будет доступен

## 🐛 Troubleshooting

Если возникнут проблемы:

1. **Сборка не проходит**: Проверьте логи в Dokploy, убедитесь что все зависимости установлены
2. **404 ошибки**: Проверьте что папка `out/` создана после сборки
3. **Изображения не загружаются**: Убедитесь что `images: { unoptimized: true }` в `next.config.js`
4. **Формы не работают**: Проверьте переменные окружения для Telegram

Проверки прогоняй именованными скриптами (`npm run lint`, `npm run typecheck`,
`npm run build`), а не угадывай команды. Автотестов в проекте нет, поэтому
сборка — не формальность, а единственная сквозная проверка.

`npm run build` выполняет статический экспорт в `out/`. Он не требует секретов,
но читает `NEXT_PUBLIC_SITE_URL`: без него `sitemap.ts`, `robots.ts` и canonical
подставят дефолт `https://likanutrition.ru`. Если проверяешь их вывод — задай
переменную явно, иначе результат ничего не доказывает.

Добавил страницу — добавь её в `src/app/sitemap.ts` (с трейлинг-слэшем, как
требует `trailingSlash: true`) и в навигацию `Header`. Добавил динамический
маршрут — напиши `generateStaticParams`, иначе экспорт упадёт.

Правки текста и цен делай в `src/lib/content/`, а не в компонентах: там же их
ищет владелец сайта.

Визуальные изменения подтверждай реальным просмотром страницы через браузерный
MCP, а не только успешной сборкой: сборка не видит съехавшую вёрстку.

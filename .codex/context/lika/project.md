# Лендинг нутрициолога Лики Надточеевой

Next.js 14 App Router, собранный в статику (`output: 'export'`) и отданный nginx
из Docker-образа. Контент лежит кодом в `src/lib/content/` и Markdown-файлами
блога. Прод — Dokploy, домен `likanutrition.ru`, деплой по пушу в `main`.

## Чего никогда не делать

- **Пушить в `main` без спроса.** Пуш = деплой на прод. Это решение человека.
- **Писать серверный код.** `output: 'export'` означает, что рантайма нет:
  route handlers, `middleware.ts`, серверные экшены, ISR и `revalidate` в этой
  сборке не работают. Сборка либо упадёт, либо молча выкинет страницу.
- **Добавлять динамический сегмент без `generateStaticParams`.** Страница
  `blog/[slug]` существует только потому, что список слагов известен на сборке.
- **Класть секрет в `NEXT_PUBLIC_*`.** Эти значения инлайнятся в клиентский
  бандл и видны любому посетителю. Телеграм-токен форм уже такой — считать его
  публичным и не добавлять к нему ничего чувствительнее.
- **Ломать соответствие `trailingSlash: true` и путей в `sitemap.ts`.** Адреса в
  карте сайта заканчиваются слэшем; расхождение даёт редиректы и дубли в индексе.
- **Менять прод без подтверждения пользователя.** Перевыкат стирает следы.
- **Считать сборку пройденной, если её не запускали.** Автотестов нет, поэтому
  `npm run build` — единственная настоящая проверка кода целиком.

# Чеклист для деплоя в Dokploy

## ✅ Проверка перед деплоем

### 1. Переменные окружения

Убедитесь, что в Dokploy настроены следующие переменные окружения:

- `NEXT_PUBLIC_SITE_URL` - URL сайта (например: `https://lika-nutrition.ru`)
- `NEXT_PUBLIC_GOOGLE_VERIFICATION` - код верификации Google Search Console (опционально)
- `NEXT_PUBLIC_YANDEX_VERIFICATION` - код верификации Yandex Webmaster (опционально)
- `NEXT_PUBLIC_TELEGRAM_BOT_TOKEN` - токен Telegram бота для форм (опционально)
- `NEXT_PUBLIC_TELEGRAM_CHAT_ID` - ID чата для получения сообщений (опционально)

### 2. Файлы для деплоя

Убедитесь, что в репозитории есть все необходимые файлы:

- ✅ `Dockerfile` - многоэтапная сборка
- ✅ `docker-compose.yml` - конфигурация для Dokploy
- ✅ `nginx.conf` - конфигурация nginx
- ✅ `.dockerignore` - исключение ненужных файлов
- ✅ `next.config.js` - конфигурация Next.js
- ✅ `package.json` - зависимости проекта

### 3. Проверка сборки

Перед деплоем убедитесь, что проект собирается локально:

```bash
npm install
npm run build
```

Проверьте, что папка `out/` создана и содержит статические файлы.

### 4. Docker сборка

Проверьте Docker сборку локально:

```bash
docker-compose build
docker-compose up -d
```

Сайт должен быть доступен на http://localhost:3000

### 5. Проверка после деплоя

После деплоя проверьте:

1. ✅ Сайт открывается по основному URL
2. ✅ Все изображения загружаются
3. ✅ Формы работают (если настроен Telegram)
4. ✅ `/robots.txt` доступен
5. ✅ `/sitemap.xml` доступен
6. ✅ Нет ошибок в консоли браузера
7. ✅ Адаптивность на мобильных устройствах
8. ✅ Security headers работают (проверьте через https://securityheaders.com/)

## 🔧 Настройка в Dokploy

### Шаг 1: Создание проекта

1. Войдите в Dokploy
2. Создайте новый проект
3. Выберите тип: **Docker Compose**
4. Подключите Git репозиторий
5. Укажите ветку (обычно `main` или `master`)

### Шаг 2: Переменные окружения

Добавьте переменные окружения в настройках проекта в Dokploy.

### Шаг 3: Порты

- **Внешний порт**: настройте в Dokploy (обычно через Traefik)
- **Внутренний порт**: 80 (уже настроен в docker-compose.yml)

### Шаг 4: Деплой

Нажмите "Deploy" в Dokploy.

## 🐛 Troubleshooting

### Проблема: Сборка не проходит

**Решение**: 
- Проверьте логи в Dokploy
- Убедитесь, что все зависимости в `package.json`
- Проверьте, что Node.js версия совместима (требуется 18+)

### Проблема: Сайт показывает 404

**Решение**: 
- Проверьте, что папка `out/` создана после сборки
- Проверьте конфигурацию nginx
- Убедитесь, что `next.config.js` содержит `output: 'export'`

### Проблема: Изображения не загружаются

**Решение**: 
- Убедитесь, что `images: { unoptimized: true }` в `next.config.js`
- Проверьте пути к изображениям в `public/images/`

### Проблема: Формы не работают

**Решение**: 
- Проверьте переменные окружения `NEXT_PUBLIC_TELEGRAM_BOT_TOKEN` и `NEXT_PUBLIC_TELEGRAM_CHAT_ID`
- Проверьте логи в консоли браузера
- Убедитесь, что токен и chat ID правильные

### Проблема: Security headers не работают

**Решение**: 
- Security headers настроены в `nginx.conf`
- Они работают на уровне сервера после деплоя
- Проверьте через https://securityheaders.com/

# Инструкция по деплою в Dokploy

## Подготовка

1. Убедитесь, что проект собирается локально:
```bash
npm run build
```

2. Проверьте, что папка `out/` создана и содержит статические файлы.

## Деплой в Dokploy

### Вариант 1: Через Dockerfile (рекомендуется)

1. В Dokploy создайте новый проект
2. Подключите репозиторий Git
3. Выберите тип проекта: **Dockerfile**
4. Dokploy автоматически найдет `Dockerfile` и соберет образ
5. Настройте порт: **80** (внутренний порт nginx)
6. Запустите деплой

### Вариант 2: Через docker-compose.yml

1. В Dokploy создайте новый проект
2. Подключите репозиторий Git
3. Выберите тип проекта: **Docker Compose**
4. Dokploy использует `docker-compose.yml`
5. Настройте порты и переменные окружения
6. Запустите деплой

## Переменные окружения

Если нужно, добавьте в Dokploy:

- `NEXT_PUBLIC_SITE_URL` - URL сайта (по умолчанию: https://lika-nutrition.ru)
- `NEXT_PUBLIC_GOOGLE_VERIFICATION` - код верификации Google
- `NEXT_PUBLIC_YANDEX_VERIFICATION` - код верификации Yandex

## Проверка после деплоя

1. Проверьте, что сайт открывается
2. Проверьте `/robots.txt` и `/sitemap.xml`
3. Проверьте, что все изображения загружаются
4. Проверьте консоль браузера на ошибки

## Локальная проверка Docker образа

### Быстрая проверка (рекомендуется)

```bash
# Запустите скрипт проверки
./test-docker.sh
```

Скрипт автоматически:
- Проверит Docker
- Остановит старые контейнеры
- Соберет образ
- Запустит контейнер
- Проверит доступность сайта
- Проверит security headers
- Покажет логи

### Ручная проверка

```bash
# Сборка образа
docker-compose build

# Запуск контейнера
docker-compose up -d

# Проверка статуса
docker-compose ps

# Просмотр логов
docker-compose logs -f

# Остановка контейнера
docker-compose down
```

Сайт будет доступен на http://localhost:3000

## Troubleshooting

### Проблема: 404 на всех страницах кроме главной
**Решение**: Проверьте конфигурацию nginx - должен быть `try_files $uri $uri/ $uri.html /index.html;`

### Проблема: Изображения не загружаются
**Решение**: Убедитесь, что в `next.config.js` установлено `images: { unoptimized: true }`

### Проблема: Security headers не работают
**Решение**: Security headers настроены в `nginx.conf`, они будут работать после деплоя
